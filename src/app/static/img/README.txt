Thư mục ảnh giao diện (Quân). Web chỉ dùng 3 ảnh, tên file phải đúng như sau
(đuôi .jpg, .jpeg, .png hoặc .webp đều được):

  hoa_sen              ảnh bên trái ô tìm kiếm ở trang đầu (nên là ảnh dọc, khoảng 600x800)
  chim_lac             hình chim Lạc ở chân trang: PNG NỀN TRONG SUỐT, chỉ lấy hình dáng,
                       màu do web tự tô
  hoa_van_trong_dong   hoa văn mặt trống đồng làm nền mờ khu tìm kiếm (PNG nền trong suốt là đẹp nhất)

Muốn đổi ảnh: chép ảnh của bạn vào thư mục này, đổi tên cho đúng (ví dụ hoa_sen.jpg),
rồi bấm Ctrl + F5 trên trình duyệt. Thiếu file nào thì web tự lấy ảnh mặc định trên mạng.
Lấy lại ảnh mặc định: xóa file đó rồi chạy  python -m src.app.images
